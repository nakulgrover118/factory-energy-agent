What the system answers 03 / 08

Six kinds of question, each with a defined answer

Capability Example request What the answer contains
Bill bridge “Why did the bill go up 15%?” A split into five causes that adds up to the total
Top users “Which assets use the most energy?” A ranked list with each asset’s share of the total
Idle waste “How much energy is used when nothing is produced?” Idle-load kWh by asset and the hours it happens
Savings “What should we do first?” Actions with kWh, money and CO2e saved, each as a range
Ranking “Which action pays back fastest?” Actions ranked by payback and ease of doing
Out of scope “What will the tariff be next year?” A clear “not in the data”, not a guess
Answer types returned by /analyze
decomposition recommendation calculated not_in_data clarification_needed refused

The system never controls equipment. Every action is a suggestion that a manager approves, so requires_approval is always true.
