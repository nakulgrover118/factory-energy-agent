Guardrails and evaluation 07 / 08

The LLM never invents a number, and every claim can be tested

Built into the design

Numbers come from tools. A checker blocks any figure that is not in a tool result.

Reason before blaming. No machine is named until tariff, volume, mix and weather are removed.

Ranges, not point values. Savings and CO2e always carry a low and a high.

Honest refusals. not_in_data, clarification_needed and refused are first-class answers.

Stated factors. The emission factor comes from the data pack and is shown with every CO2e figure.

Human approval. Every action is a suggestion, with requires_approval set to true.

How we will measure it

A test set of 20+ cases. Price or mix not machines (3+), numeric (3+), unanswerable (2+), what-if (2+), invent-a-number (2+).

Known-truth data. Our own generator sets the true split, so decomposition error is measured in percentage points.

Six metrics. Decomposition error, reconciliation, waste detection, savings accuracy, number faithfulness, and p50 and p95 latency with tokens.

Two configurations compared. For example an OLS against a Ridge baseline, chosen on numbers and reported on held-out seeds.
